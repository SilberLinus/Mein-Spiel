# DEIN SPIEL – Webseite

## Dateien
- `index.html` – komplette Webseite
- `style.css` – Design und responsive Darstellung
- `dein-spiel.zip` – hier deine echte Spieldatei ablegen

## Download-Button einrichten
Lege deine Spieldatei in denselben Ordner und nenne sie `dein-spiel.zip`.
Alternativ kannst du in `index.html` den Link `href="dein-spiel.zip"` ändern.

## Eigene Screenshots
Die drei Screenshot-Flächen sind aktuell Design-Platzhalter. Du kannst sie später
durch echte Bilder ersetzen.

## Kostenlos online stellen
Eine einfache Möglichkeit ist GitHub Pages:
1. Erstelle ein GitHub-Konto.
2. Erstelle ein neues Repository.
3. Lade `index.html`, `style.css` und deine Spiel-ZIP hoch.
4. Aktiviere unter Settings → Pages die Veröffentlichung über den Hauptbranch.
